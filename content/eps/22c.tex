\subsection{Episode 22c: Subjects please}

\DndDropCapLine{A}s the days draw in, I find myself watched by Gary more and more. His connection with the polices, however useful, could end up being very troublesome. If only he would help me test the new concoctions on him, he was such a valuable subject. Since we started testing on ourselves, its getting harder and harder to tell which effect is associated with which dose. I need a wider market for distribution. Tomorrow I'll escape through the tunnels while Gary is at work and talk with the thieves guild. Maybe its time to set up my own network.... I must find more test subjects, and record all that we are finding. If we make a little money in the process then so be it.\medskip

I must get more data, and more resources. The Guild has given me access to the tamest of materials, but I long for the more exotic. The magic bush grows both in my waking dreams and on the balcony, there must be more like it, there must be so much more out there to be found, and tested.....\medskip
